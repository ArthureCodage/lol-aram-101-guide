## 📜 Course Syllabus

1. **[Introduction & ARAM Mindset](https://arthurecodage.github.io/lol-aram-101-guide/#introduction)**
   - The 4 Golden Rules (No Back, Shop on Death, Hexgates, Snowball/Mark-Dash).
   - Gold management and strategic death timing.
2. **[AD vs AP & Damage Types](https://arthurecodage.github.io/lol-aram-101-guide/#ad-vs-ap)**
   - Physical, Magic, and True Damage breakdown.
   - Identifying AD vs AP ratios in ability tooltips.
3. **[Complete Stat Glossary](https://arthurecodage.github.io/lol-aram-101-guide/#statistiques)**
   - Attack Speed & Critical Strike Chance.
   - Ability Haste (CDR).
   - Lethality vs % Armor Penetration.
   - Life Steal vs Physical Vamp vs Omnivamp.
   - Anti-Healing debuff: **Grievous Wounds**.
4. **[Item Anatomy (Passives vs Actives)](https://arthurecodage.github.io/lol-aram-101-guide/#objets)**
   - Automatic passives vs Manual active hotkeys (slots 1-6).
   - Named Unique Passives stacking rules.
5. **[Crowd Control & Status Effects](https://arthurecodage.github.io/lol-aram-101-guide/#cc-status)**
   - Hard CC vs Soft CC.
   - Why Knockup (Airborne) is the King of CC.
   - Tenacity mechanics.
6. **[Special ARAM: MAYHEM](https://arthurecodage.github.io/lol-aram-101-guide/#aram-mayhem)**
   - Augment Tiers (Silver, Gold, Prismatic).
   - Prismatic items & wild build synergies.

## 🚀 Local PDF Generation

This repository includes a modern esports dark-themed web layout and an automated Node.js script using `puppeteer-core` to compile the guide into high-resolution A4 PDFs for both French and English versions.

### Installation & PDF Build

```bash
# 1. Clone the repository
git clone https://github.com/ArthureCodage/lol-aram-101-guide.git
cd lol-aram-101-guide

# 2. Install dependencies
npm install

# 3. Build PDFs (FR & EN)
npm run build:pdf
```

Output files:
- 📁 `League_of_Legends_ARAM_101_Guide.pdf` (French)
- 📁 `League_of_Legends_ARAM_101_Guide_EN.pdf` (English)
